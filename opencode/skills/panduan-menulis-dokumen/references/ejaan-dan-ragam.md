# Rujukan Ejaan dan Ragam

Berkas ini dibaca saat menjalankan Bagian 4 SKILL.md, yaitu lintasan verifikasi setelah draf selesai. Tidak perlu dibaca saat menulis draf.

Kedua tabel di sini contoh, bukan daftar tertutup. Kata yang tidak ada di sini dan ejaannya diragukan tetap dicek ke `kbbi.kemdikbud.go.id`.

## 1. Ejaan baku

### 1.1 Kesalahan paling sering

| Salah | Baku |
|---|---|
| praktek | praktik |
| analisa | analisis |
| resiko | risiko |
| sekedar | sekadar |
| silahkan | silakan |
| jadual | jadwal |
| ijin | izin |
| karir | karier |
| hutang | utang |
| jaman | zaman |
| nomer | nomor |
| respon | respons |

### 1.2 Imbuhan dan peluluhan

| Salah | Baku |
|---|---|
| merubah | mengubah |
| mengkonfirmasi | mengonfirmasi |
| mempublikasikan | memublikasikan |
| mengkoordinasi | mengoordinasi |
| memfokuskan | memfokuskan, tetap tidak luluh |
| mensukseskan | menyukseskan |
| mentargetkan | menargetkan |
| memproduksi | memproduksi, tetap tidak luluh |
| mencabut | mencabut, tetap tidak luluh |
| pengrusakan | perusakan |

Konsonan k, p, s, dan t luluh saat bertemu awalan me-. Konsonan pada gugus seperti pr, tr, dan kl tidak luluh, karena itu memproduksi dan memfokuskan tetap seperti itu.

### 1.3 Serapan berakhiran -si dan -tas

| Salah | Baku |
|---|---|
| aktifitas | aktivitas |
| efektifitas | efektivitas |
| kreatifitas | kreativitas |
| produktifitas | produktivitas |
| sportifitas | sportivitas |

Kata dasarnya memakai f, tetapi bentuk -tas memakai v: aktif jadi aktivitas.

## 2. Ragam cakapan dan padanan bakunya

Dipakai saat mengubah tulisan nonformal menjadi formal, atau saat memeriksa apakah ragamnya tercampur.

### 2.1 Kata tugas

| Cakapan | Baku |
|---|---|
| tapi | tetapi |
| kalau | jika atau apabila |
| makanya | karena itu |
| terus | lalu atau kemudian |
| sama | dengan atau dan |
| doang | saja |
| aja | saja |
| kan | bukan begitu, atau buang |
| sih | buang |
| deh | buang |

### 2.2 Kata tanya dan penunjuk

| Cakapan | Baku |
|---|---|
| gimana | bagaimana |
| kenapa | mengapa |
| gitu | begitu |
| gini | begini |
| kayak | seperti |
| ini nih | ini |

### 2.3 Kata kerja

| Cakapan | Baku |
|---|---|
| bikin | membuat |
| ngasih | memberi |
| ngerjain | mengerjakan |
| ngecek | memeriksa |
| ngirim | mengirim |
| nyiapin | menyiapkan |
| dapet | dapat atau memperoleh |
| kepake | terpakai |

### 2.4 Negasi dan penegas

| Cakapan | Baku |
|---|---|
| ngga, gak, nggak | tidak |
| bukannya | bukan |
| udah | sudah |
| belom | belum |
| banget | sangat, atau ganti dengan angka sesuai 2.8 |
| paling | paling, tetap baku |

### 2.5 Ejaan cakapan yang tetap dilarang

Pada ragam nonformal, kata cakapan boleh dipakai, tetapi ejaannya tetap baku.

| Dilarang | Dipakai |
|---|---|
| kalo | kalau |
| ngga, gk | nggak |
| udh, sdh | udah |
| yg | yang |
| dgn | dengan |
| tdk | tidak |
| krn | karena |
| utk | untuk |

Singkatan seperti yg, dgn, dan tdk tidak dipakai pada ragam mana pun, termasuk nonformal.
